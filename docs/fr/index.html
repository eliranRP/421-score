421 score est une feuille de café pour le 421. On inscrit les charges avec de grands +/−. L’application ne lance pas les dés et ne joue pas la partie.

Tout reste sur le téléphone : pas de compte, pas de suivi, pas de réseau. Les derniers noms restent sur l’appareil.

Aide

  • 2 à 6 joueurs, noms facultatifs
  • Marques de maison : 421, nénette, macque
  • Manche suivante, annuler, reset manche, nouvelle table

Une question : ouvrir une issue GitHub.
